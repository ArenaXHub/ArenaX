One activity, as the class does it

Class 7 · Card sorting as a classifier

  1. The storyThe canteen wants a machine that guesses which snack each class will finish first. How would it learn?
  2. Sort by ruleGroups sort 24 picture cards by a written rule ("fried / not fried"). Count the mistakes.
  3. Sort by examplesGroups get six labelled examples and no rule. They sort the rest. Count the mistakes again.
  4. What I madeThe sorted set photographed on the board plus a hand-drawn right/wrong tally for both rounds.
  5. Tell it backTo a partner, one minute: what I made, why it works, when it would go wrong ("a snack we had no example of").

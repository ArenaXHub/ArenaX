ArenaX Student Program

Student-Led • Data-Driven • Real Event Execution

ArenaX is inviting motivated students to join the founding execution team for its pilot project — the ArenaX Badminton Skill Challenge.

About the Program

ArenaX is building a student-driven team to design and execute structured sports events where performance is evaluated, ranked, and certified.

Students involved in the program will contribute to real event planning, participant management, promotion, and data collection during live sports competitions.

Roles Available

Event Operations

Planning event format, match schedules, and on-ground execution.

Event Data & Analytics

Collecting match data and organizing performance records for rankings and certification.

Digital Promotion

Managing posters, social media announcements, and event visibility.

Brand Partnerships

Exploring sponsorship opportunities and building relationships with sports brands.

Participation Outreach

Helping grow event participation through campus networks and sports groups.

What Students Gain

Students actively contributing to ArenaX projects may receive:

Real Event Execution Experience
Exposure to Data-Driven Sports Systems
Performance-Based Internship Certificates
LinkedIn Recommendations
Recognition as ArenaX Founding Team
